# ExtenderMCP23S17



Library: Rob Tillaart MCP23S17 0.8.2.

De publieke API van ExtenderMCP23S17 is de API van MCP23S17 0.8.2 van Rob Tillaart. Een wissel van bibliotheek breekt sketches die deze API gebruiken.

GedeeldeBus: SPI. Per instantie is CS exclusief; SCK/MISO/MOSI zijn gedeeld. `Activeren()` voert `begin()` en `isConnected()` uit.

## Aansluiten

- SPI: `SCLK`, `MOSI`, `MISO`, `CS`; zestien GPIO via `GPA0`–`GPA7` en `GPB0`–`GPB7`.
- Aansluitinstellingen: `EXTENDER_MCP23S17_1_CS_PIN`, `EXTENDER_MCP23S17_2_CS_PIN`.

**Aansluit- en gebruiksgegevens uit de bestaande FrameWork-interface:**

- **Host-SPI:** `SCK/SCLK` van de module → host `np_SCK`; host `np_MOSI` → module `MOSI/SDI/DIN`; module `MISO/SDO/DOUT` → host `np_MISO`; module `CS/SS` → de exclusieve `np_CS` van deze Extender. Verbind GND en de voeding met correcte logicaniveaus.
- De gedeelde SPI-datalijnen kunnen gedeeld worden, **CS niet** met een gelijktijdig geclaimd ander apparaat. Kies een echte geschikte native CS-pin en controleer de fysieke modulebenaming.
- **GPIO:** sluit de digitale signalen aan op `GPA0`–`GPA7` en `GPB0`–`GPB7`. Dit zijn 16 digitale uitbreidingskanalen; gebruik aparte drivertrappen voor vermogenlasten.
- De bestaande `ExtenderMCP23S17` erft zowel `HardwareResourceTypeSPI` als de publieke API van Rob Tillaarts `MCP23S17`. De pinnen `EP_GPA0`–`EP_GPA7` en `EP_GPB0`–`EP_GPB7` zijn kanaalnummers 0–15.
- `Activeren()` voert `begin()` uit, bewaart de oorspronkelijke polariteit van bank A, schrijft `0x55`, leest dezelfde waarde terug en herstelt en controleert de oorspronkelijke polariteit. De SPI-`isConnected()`-melding alleen volstaat in de bestaande code niet als aanwezigheidsbewijs.
- Het bestaande voorbeeld `examples/Systeem/GedeeldeBus/Extenders/Extender_MCP23S17/Extender_MCP23S17.ino` initialiseert de lifecycle en zet vervolgens GPIO 0 als `OUTPUT` en `LOW` via `pinMode1(0, OUTPUT)` en `write1(0, LOW)`.
- Voor één Extender gebruikt de constructor de afzonderlijke CS-configuratie `EXTENDER_MCP23S17_1_CS_PIN`; bij twee exemplaren selecteert de bestaande constructor de configuratieregel met een teller (0 voor de eerste). SCK, MISO en MOSI zijn de gedeelde SPI-signalen.
- De huidige `Activeren()` gebruikt voor een echte SPI-verbindingscontrole bank-A `IPOL`: oorspronkelijke polariteit lezen, testwaarde `0x55` schrijven en teruglezen, oorspronkelijke waarde herstellen en opnieuw lezen. Zonder geslaagde readback kan de Extender niet activeren.


**Configuratie voor deze hardware:**

- Gebruik bij een eigen configuratie `src/Configuratie/Extenders/ConfigMCP23S17.h` (het aanwezige `src/Configuratie/Extenders/ConfigMCP23S17_template.h` is een kopieersjabloon en wordt niet rechtstreeks ingelezen).
- Voor één aangesloten exemplaar: `EXTENDER_MCP23S17_AANTAL` op **1**, behalve wanneer de bestaande groeps-/setconfiguratie uitdrukkelijk een andere betekenis heeft.
- De bestaande configuratie bevat deze aansluitrelevante definities (gebruik de **werkelijke aangesloten** pinnen, adressen en referenties):
  - `EXTENDER_MCP23S17_AANTAL`: sjabloonwaarde `0`.
  - `EXTENDER_MCP23S17_1_CS_PIN`: sjabloonwaarde `HardwareResourcePin::NONE`.
  - `EXTENDER_MCP23S17_2_CS_PIN`: sjabloonwaarde `HardwareResourcePin::NONE`.

**Letterlijk constructorfragment uit de bestaande voorbeeldsketch** (alle gebruikte parent-objecten moeten zelf correct aangesloten en geïnitialiseerd zijn):

```cpp
ExtenderMCP23S17 extender(&Native, GedeeldeBusComponent::DIGITAL_PINS_MCP23S17, EXTENDER_MCP23S17_1_CS_PIN, HardwareResourcePin::NP_SCK, HardwareResourcePin::NP_MISO, HardwareResourcePin::NP_MOSI);
```

**Elektrische aansluiting en randvoorwaarden volgens Microchip:**

- Voor de **losse 28-pins MCP23S17**: VDD = 9, VSS = 10, CS = 11, SCK = 12, SI/MOSI = 13, SO/MISO = 14; A0 = 15, A1 = 16, A2 = 17, RESET = 18, INTB = 19, INTA = 20; GPA0–GPA7 = 21–28 en GPB0–GPB7 = 1–8.
- Houd RESET in niet-actieve toestand volgens de concrete schakeling en definieer A0/A1/A2 elektrisch. Voor meerdere SPI-adressen op één CS is het **HAEN**-bit relevant. De chipvoeding bedraagt volgens Microchip 1,8–5,5 V (temperatuurafhankelijk); let op SPI-logicaniveaus.
- De bestaande FrameWork-`Activeren()` controleert de verbinding door een registerwaarde te schrijven, terug te lezen en te herstellen: een correcte CS/SI/SO/SCK-aansluiting is daarvoor onmisbaar.

**Technische handleiding:** https://www.microchip.com/en-us/product/mcp23s17

**Bestaand bronbestand voor de component:** `src/Systeem/Extender/MCP23S17.h`

**Package en adresselectie:** de eerder genoemde getallen **1–28** zijn de aansluitnummers van de losse **28-pins SPDIP/SOIC/SSOP**, niet van de breakoutheader en niet van de **QFN**-behuizing. De fabrikant zegt dat `A0`, `A1` en `A2` elektrisch gedefinieerd moeten zijn, ook wanneer `HAEN=0`; pas met ingeschakelde hardware-adressering kan dezelfde CS-lijn meerdere afzonderlijke SPI-hardwareadressen aanspreken. De huidige FrameWorkconstructor configureert per instantie een **CS-resource**; koppel geen twee kaarten automatisch aan dezelfde CS zonder bewezen adreslogica.
