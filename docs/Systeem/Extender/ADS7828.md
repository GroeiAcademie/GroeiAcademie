# ExtenderADS7828

## Implementatie

- Library: **geen externe library in de huidige Extenderklasse**.
- Er is in de huidige Extenderklasse geen externe library-API die integraal wordt geërfd.

## FrameWork-integratie

Huidige overerving:

```cpp
struct ExtenderADS7828 : HardwareResourceTypeI2C
```

De huidige klasse voegt voornamelijk GedeeldeBus-/resource-integratie toe; er is geen aanvullende publieke chipspecifieke API geïnventariseerd die hier apart moet worden gedocumenteerd.

## Aansluiten

- I²C: `SDA` en `SCL`; analoge kanalen `CH0`–`CH7`.
- Aansluitinstellingen: `I2C_ADDRESS_EXTENDER_ADS7828_1`, `I2C_ADDRESS_EXTENDER_ADS7828_2`.

**Aansluit- en gebruiksgegevens uit de bestaande FrameWork-interface:**

- **Hostbus:** `ADS7828`-module `SDA` → de `SDA` van de parent-I²C-bus, `SCL` → `SCL`, `GND` → GND; de I²C-voeding en logicaniveaus moeten passen bij de module én het board.
- Stel het I²C-adres in de bestaande Extenderconfiguratie gelijk aan het fysieke adres dat de adresselectie op het bord oplevert. Bij een TCA9548A-child gebruik je de bij de constructor gekozen downstreambus.
- **Analoog:** sluit de analoge meetpunten aan op `CH0`–`CH7`. De externe/interne referentiemodus wordt door `EXTENDER_ADS7828_EXTERNE_REFERENTIE` gekozen; een externe VREF alleen bedraden volgens die keuze.
- De acht analoge ingangen komen overeen met `EP_CH0` tot en met `EP_CH7`. De code behandelt de referentie-instelling afzonderlijk voor externe en interne referentie via `EXTENDER_ADS7828_EXTERNE_REFERENTIE`.
- `Activeren()` initialiseert de referentie voordat de eerste meting wordt gebruikt. Sluit een externe referentie uitsluitend aan als die modus daadwerkelijk is geconfigureerd.

**Bestaande constructor (parameter-/pinvolgorde):**

```cpp
ExtenderADS7828(GedeeldeBusNode* parent, GedeeldeBusComponent component, HardwareResourcePin np_SDA, HardwareResourcePin np_SCL, uint8_t teller, HardwareResourceToegang Extender = HardwareResourceToegang::GEDEELD, uint8_t tcaChannel = 0xFF)
```

**Configuratie voor deze hardware:**

- Gebruik bij een eigen configuratie `src/Configuratie/Extenders/ConfigADS7828.h` (het aanwezige `src/Configuratie/Extenders/ConfigADS7828_template.h` is een kopieersjabloon en wordt niet rechtstreeks ingelezen).
- Voor één aangesloten exemplaar: `EXTENDER_ADS7828_AANTAL` op **1**, behalve wanneer de bestaande groeps-/setconfiguratie uitdrukkelijk een andere betekenis heeft.
- De bestaande configuratie bevat deze aansluitrelevante definities (gebruik de **werkelijke aangesloten** pinnen, adressen en referenties):
  - `EXTENDER_ADS7828_AANTAL`: sjabloonwaarde `0`.
  - `I2C_ADDRESS_EXTENDER_ADS7828_1`: sjabloonwaarde `I2C_ADDRESS_NONE`.
  - `I2C_ADDRESS_EXTENDER_ADS7828_2`: sjabloonwaarde `I2C_ADDRESS_NONE`.
  - `EXTENDER_ADS7828_EXTERNE_REFERENTIE`: sjabloonwaarde `0`.
  - `EXTENDER_ADS7828_REFERENTIE_MILLIVOLT`: sjabloonwaarde `2500`.

**Letterlijk constructorfragment uit de bestaande voorbeeldsketch** (alle gebruikte parent-objecten moeten zelf correct aangesloten en geïnitialiseerd zijn):

```cpp
ExtenderADS7828 extender(
  &Native,
  GedeeldeBusComponent::ADC_ADS7828,
  I2C_ADDRESS_EXTENDER_ADS7828_1, HardwareResourcePin::NP_SDA, HardwareResourcePin::NP_SCL
);
```

## Librarydocumentatie

- Deze Extender erft in de huidige implementatie geen externe library-API.
- Deze `.md` documenteert daarom de eigen FrameWork-/hardware-integratie die momenteel in de Extender aanwezig is.

**Elektrische aansluiting en randvoorwaarden volgens Texas Instruments:**

- De ADS7828 is een 12-bit, 8-kanaals ADC met I²C. TI specificeert een voedingsbereik van 2,7–5,25 V; de ingangen moeten binnen de toegelaten analoge grenzen blijven. De referentiekeuze bepaalt de omzettingsschaal.

**Technische handleiding:** https://www.ti.com/product/ADS7828
