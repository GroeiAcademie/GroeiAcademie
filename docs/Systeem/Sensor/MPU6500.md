# MPU6500

## Implementatie

- Broncode: `src/Systeem/Sensor/MPU6500.h` en `MPU6500.cpp`.
- C++-component: `MPU6500`, afgeleid van `Sensor`.
- Parent: `HardwareResourceTypeI2C*` in de constructor.
- Componentcode: `MPU6500` (0x97).
- Configuratie: `src/Configuratie/Sensoren/ConfigMPU6500_template.h`; de optionele persoonlijke versie heet telkens zonder `_template`.
- Data-kanalen: 1.
- Externe library: `MPU6500_WE.h`.
