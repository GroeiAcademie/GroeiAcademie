# RFP602

## Implementatie

- Broncode: `src/Systeem/Sensor/RFP602.h` en `RFP602.cpp`.
- C++-component: `RFP602`, afgeleid van `Sensor`.
- Parent: analoge ADC-Extender, via de generieke analoge parent-functies.
- Kanalen: maximaal vier ingangen per sensorobject, met exclusieve pinclaims.
- Configuratie: `src/Configuratie/Sensoren/ConfigRFP602_template.h`; de optionele persoonlijke versie heet `ConfigRFP602.h`.
- RUN22 bevat configuratie per set (`_SET_1` en optioneel `_SET_2`) en eigen databuffers per object.
- Metingen verlopen via de bestaande lifecycle en eventuele Data-koppeling.
