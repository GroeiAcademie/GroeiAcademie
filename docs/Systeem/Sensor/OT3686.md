# OT3686

## Implementatie

- Broncode: `src/Systeem/Sensor/OT3686.h` en `OT3686.cpp`.
- C++-component: `OT3686`, afgeleid van `Sensor`.
- Parent: `GedeeldeBusNode*` in de constructor.
- Componentcode: `OT3686` (0x85).
- Configuratie: `src/Configuratie/Sensoren/ConfigOT3686_template.h`; de optionele persoonlijke versie heet telkens zonder `_template`.
- Data-kanalen: 4.

## Uit de broncode

OT3686: DO digitaal; AO is volgens Otronic niet functioneel. Eén native interrupt per sensor, pulse count = software teller; geen Input-code.
