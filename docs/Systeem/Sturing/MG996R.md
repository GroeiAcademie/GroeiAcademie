# MG996R

## Component

MG996R-servomotor. De huidige implementatie bevat de component als header-only codevoorstel; dit document beschrijft die bestaande implementatie, niet een gevalideerde hardwarewerking.

## Implementatie

- Broncode: `src/Systeem/Sturing/MG996R.h`.
- C++-component: `MG996R`, rechtstreeks afgeleid van `GedeeldeBusNode`.
- Aansluiting: PWM-channel op PCA9685 via `WriteExtenderPWM()`.
- Bestaande aansturing: `setServoAngle(uint8_t hoek)`.
- Lifecycle: de component bevat een `Activeren()`-override en een `StopSturing()`-override voor uitschakeling.
- Configuratie: `src/Configuratie/Sturingen/ConfigMG996R_template.h`; optioneel persoonlijk `ConfigMG996R.h`.

## Aandachtspunt

Pulsgrenzen en voedingsvoorziening moeten voor het concrete exemplaar worden gevalideerd.

## Testen

De huidige implementatie bevat een voorbeeld voor deze Sturing in `examples/` en het script `extras/TestLibrarySturingen-v2.0.0.cmd`. Compilatie en hardwaregedrag zijn **niet gevalideerd**.

Configuratie: `STURING_MG996R_AANTAL`: 0 = niet opgenomen; groter dan 0 = opgenomen; het aantal objecten wordt niet begrensd.
