# SG90

## Component

SG90-servomotor. De huidige implementatie bevat de component als header-only codevoorstel; dit document beschrijft die bestaande implementatie, niet een gevalideerde hardwarewerking.

## Implementatie

- Broncode: `src/Systeem/Sturing/SG90.h`.
- C++-component: `SG90`, rechtstreeks afgeleid van `GedeeldeBusNode`.
- Aansluiting: PWM-channel op PCA9685 via `WriteExtenderPWM()`.
- Bestaande aansturing: `setServoAngle(uint8_t hoek)`.
- Lifecycle: de component bevat een `Activeren()`-override en een `StopSturing()`-override voor uitschakeling.
- Configuratie: `src/Configuratie/Sturingen/ConfigSG90_template.h`; optioneel persoonlijk `ConfigSG90.h`.

## Aandachtspunt

Pulsgrenzen en veilige toestand zijn afhankelijk van servo en belasting.

## Testen

De huidige implementatie bevat een voorbeeld voor deze Sturing in `examples/` en het script `extras/TestLibrarySturingen-v2.0.0.cmd`. Compilatie en hardwaregedrag zijn **niet gevalideerd**.

Configuratie: `STURING_SG90_AANTAL`: 0 = niet opgenomen; groter dan 0 = opgenomen; het aantal objecten wordt niet begrensd.
