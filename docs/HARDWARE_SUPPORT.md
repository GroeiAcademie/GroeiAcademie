# Hardwareondersteuning

## Officieel bij eerste release

- Arduino UNO R3
- Arduino UNO R4

Een board is pas officieel ondersteund wanneer de relevante voorbeelden compileren en de essentiële modulefuncties op echte hardware getest zijn.

## ESP32

ESP32-elektronica bestaat reeds. ESP32 wordt pas als officieel ondersteund platform vermeld na een afzonderlijke compatibiliteits-, timing- en documentatiecontrole.

## Sensoren

Een sensor wordt per meetdoel beoordeeld op betrouwbaarheid, resolutie, bereik, snelheid, kalibratie, comfort en praktische plaatsing. Geschiktheid voor één meetdoel impliceert geen geschiktheid voor een ander meetdoel.
