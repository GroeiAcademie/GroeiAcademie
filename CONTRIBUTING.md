# Bijdragen

Bedankt dat je wilt bijdragen aan GroeiAcademie Framework.

## Mogelijke bijdragen

Code, voorbeelden, documentatie, vertalingen, meetprotocollen, nieuwe modules, hardwaretests, bugmeldingen en code reviews zijn welkom.

## Voor grotere wijzigingen

Open eerst een issue met:

- het leer- of onderzoeksdoel
- de voorgestelde wijziging
- wat objectief gemeten wordt
- benodigde hardware
- gevolgen voor UNO R3 en UNO R4
- gevolgen voor publieke API en documentatie

## Codeprincipes

- respecteer bestaande naamgeving en commentaren
- voeg geen onnodige afhankelijkheden toe
- houd ruwe data, berekeningen en interpretaties gescheiden
- pas de publieke API alleen aan na bespreking
- voeg voorbeelden en tests toe wanneer gedrag verandert
- beschrijf beperkingen en foutbronnen

## Communitybeginsel

Verbeteringen aan het framework horen terug te vloeien naar de community. Bijdragen die de community structureel afhankelijk maken van gesloten onderdelen worden kritisch beoordeeld.
